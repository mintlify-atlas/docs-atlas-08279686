## Introduction

AutoGOAL provides a powerful command-line interface (CLI) that allows you to perform machine learning tasks, manage datasets, and explore contrib libraries without writing a single line of code. The CLI is built with [Typer](https://typer.tiangolo.com/) and provides a rich, interactive experience with helpful messages and progress bars.

## Installation

The CLI is automatically available after installing AutoGOAL:

```bash
pip install autogoal
```

For full functionality with all contrib libraries:

```bash
pip install autogoal[contrib]
```

## Getting Help

To see all available commands, run:

```bash
autogoal --help
```

<Note>
The CLI uses emoji icons (🤩, 🔍, 🤖, etc.) to make the interface more friendly and easier to navigate.
</Note>

### Command-Specific Help

Each command and subcommand has detailed help information:

```bash
# Get help for ml commands
autogoal ml --help

# Get help for a specific command
autogoal ml fit --help

# Get help for data commands
autogoal data --help

# Get help for contrib commands
autogoal contrib --help
```

## Quick Start Examples

### Train an AutoML Model

Train a model on a CSV dataset:

```bash
autogoal ml fit train.csv --target class_label
```

### Make Predictions

Use a trained model to make predictions:

```bash
autogoal ml predict test.csv --model ./storage --output predictions.csv
```

### Download a Dataset

Download one of AutoGOAL's built-in datasets:

```bash
autogoal data download movie_reviews
```

### List Available Algorithms

Explore available contrib algorithms:

```bash
autogoal contrib list --verbose
```

## Command Structure

The CLI follows a consistent structure:

```bash
autogoal [GROUP] [COMMAND] [ARGUMENTS] [OPTIONS]
```

**Example breakdown:**

```bash
autogoal ml fit train.csv --target price --iterations 100
│         │  │   │         │              │
│         │  │   │         │              └─ Option with value
│         │  │   │         └──────────────── Option flag
│         │  │   └────────────────────────── Required argument
│         │  └────────────────────────────── Command
│         └───────────────────────────────── Command group
└─────────────────────────────────────────── Main program
```

## File Format Support

AutoGOAL CLI supports multiple file formats:

### CSV Files

```bash
autogoal ml fit data.csv --target label
```

CSV files are auto-detected and parsed with pandas. The target column is assumed to be the last column if not specified.

### JSON Files

```bash
autogoal ml fit data.json --target label --format json
```

JSON files should contain tabular data in a format compatible with pandas `read_json`.

## Output and Logging

The CLI provides rich output with:

- **Progress bars** for long-running operations
- **Color-coded messages** for different types of information
- **Emoji indicators** for visual clarity
- **Tables** for structured data display
- **Formatted error messages** with helpful debugging information

### Example Output

When training a model:

```
🏃 Training on 1000 items.
[Progress bar with iteration details]

```

## Error Handling

When an error occurs, the CLI provides:

1. A clear error message
2. An option to view the full traceback for debugging

```
⚠️  The command failed with message:
"Input format not recognized. Must be either CSV or JSON."

❓ Do you want to inspect the traceback? [y/N]
```

<Tip>
Press `y` to see the full Python traceback when debugging issues.
</Tip>

## Working with Paths

The CLI uses Python's `Path` objects internally:

- **Relative paths** are resolved from the current working directory
- **Absolute paths** can be used for precise file locations
- **Home directory** expansion (`~`) is supported

```bash
# Relative path
autogoal ml fit ./data/train.csv

# Absolute path
autogoal ml fit /home/user/datasets/train.csv

# Home directory
autogoal ml fit ~/datasets/train.csv
```
