AutoGOAL provides a comprehensive collection of built-in datasets for various machine learning tasks. These datasets are automatically downloaded and cached locally, making it easy to experiment with different problem domains.

## Dataset Module

The `autogoal.datasets` module provides utilities for loading and managing datasets:

```python
from autogoal.datasets import datapath, download
```

### Key Functions

<CardGroup cols={2}>
  <Card title="datapath()" icon="folder">
    Returns a `Path` object pointing to the dataset storage location
  </Card>
  <Card title="download()" icon="download">

  </Card>
  <Card title="get_datasets_list()" icon="list">

## Dataset Categories

AutoGOAL includes datasets spanning multiple domains:

<Accordion title="Image Classification">

<Accordion title="Synthetic/Testing Datasets">

</Accordion>

## Data Storage

Datasets are automatically downloaded and cached in the user's home directory:

```python
from autogoal.datasets import datapath

# Default storage location: ~/.autogoal/data/
path = datapath("movie_reviews")
print(path)  # PosixPath('/home/user/.autogoal/data/movie_reviews')
```

<Note>
  Datasets are downloaded only once and cached locally. Subsequent calls to `load()` will use the cached version.
</Note>

## Typical Usage Pattern

Most datasets follow a consistent loading pattern:

```python
from autogoal.datasets import <dataset_name>

# Load the dataset
X_train, y_train, X_test, y_test = <dataset_name>.load()

# Use with AutoGOAL
from autogoal.ml import AutoML

automl = AutoML()
automl.fit(X_train, y_train)
score = automl.score(X_test, y_test)
```

## Dataset Metadata

AutoGOAL maintains a remote metadata file that tracks available datasets and their download URLs:

```python
from autogoal.datasets import get_datasets_list

# Get all available datasets
datasets = get_datasets_list()
print(datasets.keys())
```

The metadata is fetched from:
```
https://raw.githubusercontent.com/autogoal/datasets/master/datasets.json
```

<Note>
  If you're offline, AutoGOAL will use a locally cached version of the datasets metadata.
</Note>

## Error Handling

Datasets include built-in error handling for network issues:

```python
try:
    X, y = some_dataset.load()
except Exception as e:
    print("Error loading data. Check your connection.")
    print("Delete partially downloaded files and retry.")
```
