## What is AutoGOAL?

AutoGOAL is a Python framework for automatically finding the best way to solve a given task. It has been designed mainly for **Automated Machine Learning** (AutoML) but can be used in any scenario where you have several possible ways to solve a given problem.

Technically speaking, AutoGOAL is a framework for **program synthesis** — finding the best program to solve a given problem, provided that you can describe the space of all possible programs. AutoGOAL provides low-level components to define different spaces and efficiently search in them.

## How It Works

AutoGOAL works by defining a **search space** of possible machine learning pipelines and using **optimization algorithms** to find the best pipeline for your specific problem.

<Steps>
  <Step title="Define Input and Output Types">
    Specify what kind of data you have and what you want to predict using AutoGOAL's semantic type system.
  </Step>
  
  <Step title="Configure the Search">
    Choose which algorithms to include, how long to search, and which optimization strategy to use.
  </Step>
  
  <Step title="Let AutoGOAL Search">
    AutoGOAL automatically generates and evaluates pipelines, learning from each iteration.
  </Step>
  
  <Step title="Get the Best Pipeline">
    Retrieve the best performing pipeline and use it for predictions on new data.
  </Step>
</Steps>

## Simple Example

Here's a minimal example showing how to use AutoGOAL for classification:

```python
from autogoal.datasets import cars
from autogoal.kb import MatrixContinuousDense, Supervised, VectorCategorical
from autogoal.ml import AutoML

# Load a dataset
X, y = cars.load()

# Create an AutoML instance
automl = AutoML(
    input=(MatrixContinuousDense, Supervised[VectorCategorical]),
    output=VectorCategorical
)

# Search for the best pipeline
automl.fit(X, y)

# View results
print(automl.best_pipeline_)
print(automl.best_score_)
```

<Note>
This example runs for about 5 minutes by default. You can adjust the search time using the `search_kwargs` parameter.
</Note>

## Use Cases

AutoGOAL is designed for researchers and practitioners who need to:

- **Quickly prototype** machine learning solutions without manual pipeline engineering
- **Benchmark** different ML approaches on custom datasets
- **Automate** repetitive hyperparameter tuning and algorithm selection
- **Explore** the space of possible solutions for complex problems
- **Build** AutoML systems with custom algorithms and search strategies
