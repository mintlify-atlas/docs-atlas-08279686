## Your First AutoGOAL Pipeline

This guide will walk you through creating your first automated machine learning pipeline with AutoGOAL. In just a few minutes, you'll train a classifier on a real dataset.

<Steps>
  <Step title="Install AutoGOAL">
    First, install AutoGOAL using pip:

    ```bash
    pip install autogoal
    ```

    For full machine learning support, install the contrib dependencies:

    ```bash
    pip install autogoal[contrib]
    ```

    <Note>
    See the [Installation Guide](/installation) for more details on dependencies and Docker setup.
    </Note>
  </Step>

  <Step title="Import Required Modules">
    Import the AutoML class and semantic types:

    ```python
    from autogoal.datasets import cars
    from autogoal.kb import MatrixContinuousDense, Supervised, VectorCategorical
    from autogoal.ml import AutoML
    ```
  </Step>

  <Step title="Load a Dataset">
    AutoGOAL includes several built-in datasets. Let's use the Cars dataset:

    ```python
    # Load the Cars classification dataset
    X, y = cars.load()

    print(f"Dataset shape: {X.shape}")
    print(f"Number of samples: {len(y)}")
    ```

    The Cars dataset contains vehicle characteristics and their classification.
  </Step>

  <Step title="Create and Train AutoML">
    Now create an AutoML instance and let it find the best pipeline:

    ```python
    # Create AutoML instance with input/output types
    automl = AutoML(
        input=(MatrixContinuousDense, Supervised[VectorCategorical]),
        output=VectorCategorical
    )

    # Search for the best pipeline (runs for ~5 minutes by default)
    automl.fit(X, y)

    # View the results
    print("Best pipeline:", automl.best_pipeline_)
    print("Best score:", automl.best_score_)
    ```

    <Note>
    The search runs for approximately 5 minutes by default. You can adjust this using the `search_kwargs` parameter.
    </Note>
  </Step>
</Steps>

## Complete Example

Here's the complete code in one block:

```python
from autogoal.datasets import cars
from autogoal.kb import MatrixContinuousDense, Supervised, VectorCategorical
from autogoal.ml import AutoML

# Load dataset
X, y = cars.load()

# Create and configure AutoML
automl = AutoML(
    input=(MatrixContinuousDense, Supervised[VectorCategorical]),
    output=VectorCategorical
)

# Train and search for best pipeline
automl.fit(X, y)

# Print results
print("Best pipeline:", automl.best_pipeline_)
print("Best score:", automl.best_score_)
```

<Tip>
Copy this code and run it in your Python environment to see AutoGOAL in action!
</Tip>

## Using Your Own Data

To use AutoGOAL with your own data:

```python
import numpy as np
from autogoal.ml import AutoML
from autogoal.kb import MatrixContinuousDense, Supervised, VectorCategorical

# Your data as numpy arrays
X = np.array([...])  # Features
y = np.array([...])  # Labels

# Create AutoML with appropriate types
automl = AutoML(
    input=(MatrixContinuousDense, Supervised[VectorCategorical]),
    output=VectorCategorical
)

# Fit and predict
automl.fit(X, y)
predictions = automl.predict(X)
```

<Note>
Make sure to choose the correct semantic types for your data. See [Semantic Types](/concepts/semantic-types) for more information.
</Note>

## Adding Logging

Monitor the search progress with built-in loggers:

```python
from autogoal.ml import AutoML
from autogoal.search import ConsoleLogger
from autogoal.datasets import cars

X, y = cars.load()

automl = AutoML(
    input=(MatrixContinuousDense, Supervised[VectorCategorical]),
    output=VectorCategorical
)

# Add a logger to see progress
automl.fit(X, y, logger=ConsoleLogger())
```

For more beautiful output, use `RichLogger`:

```python
from autogoal.search import RichLogger

automl.fit(X, y, logger=RichLogger())
```

## Customizing the Search

Control how long AutoGOAL searches and what resources it uses:

```python
from autogoal.ml import AutoML
from autogoal.utils import Min, Gb

automl = AutoML(
    input=(MatrixContinuousDense, Supervised[VectorCategorical]),
    output=VectorCategorical,
    search_iterations=50,  # Number of pipelines to try
    search_kwargs=dict(
        search_timeout=10 * Min,      # Total search time
        evaluation_timeout=5 * Min,   # Max time per pipeline
        memory_limit=4 * Gb,          # Memory limit per pipeline
    )
)

automl.fit(X, y)
```

## What Happens Behind the Scenes?

When you call `automl.fit()`, AutoGOAL:

1. **Discovers** available machine learning algorithms from contrib libraries
2. **Generates** a search space of possible pipelines based on semantic types
3. **Samples** pipeline candidates using probabilistic grammatical evolution
4. **Evaluates** each pipeline with cross-validation
5. **Learns** from successful pipelines to guide future sampling
6. **Returns** the best performing pipeline
